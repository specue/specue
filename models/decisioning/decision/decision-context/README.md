Решение относится к чему-то в системе: 
- к слою
- области
- заинтересованным в нём людям. 

Это его контекст.

Методология не определяет все возможные области каждой системы,
поэтому в каждой системе и ее подсистемах эти области определяются индивидуально.

Решение размечается по этим областям.

Примеры:
- слой системы: `domain`, `application`, `infrastructure`
- заинтересованные — чьи интересы затрагивает решение
</dec-body>
