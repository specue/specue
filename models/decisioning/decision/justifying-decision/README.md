Обоснование — это список отвергнутых вариантов с опциональным объяснением отвергнуты. Варианты: что еще рассматривалось. 

Обоснование опционально само по себе: если выбор был очевиден или вариант
один — обосновывать нечего.

Обоснование зафиксировано в прошлом, в момент принятия решения. С течением времени, то, на что оно сылается, может меняться, это повод для пересмотра решения уже в будущем.

Пример:

Решение: Хранить заказы в Postgres
Альтернативы:
  - MongoDB - данные заказов реляционные, документная модель не подходит
  - MySQL - не на столько же удобная работа с JSON
