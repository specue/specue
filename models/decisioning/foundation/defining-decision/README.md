Решение — зафиксированный ответ на проблему.

Решение не существует без проблемы: проблема определяет о чём решение.

Примеры:

Проблема: Как определять проблему
Решение: Проблема формулируется вопросом 'как'

Проблема: Как разрабатывать софт на основе принятых решений
Решение: Принимать решения и фиксировать их

Проблема: Как хранить состояние сессии 
Решение: Хранить в Redis с TTL 24 часа

Проблема: Как разделять слои в архитектуре
Решение: Использовать Clean Architecture
