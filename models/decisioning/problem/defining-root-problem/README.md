Где провести границу корня — решает автор. Объективного критерия нет:
любую проблему можно обосновать глубже через ещё одно решение, но цепочка
причинности бесконечна. Останавливаешься там, где дальнейшее обоснование
перестаёт менять нижестоящие решения.

Границу можно пересмотреть в любой момент, но это может потребовать
пересмотра всех нижестоящих решений. Согласованность смыслов машина
не проверит — это делается вручную.
