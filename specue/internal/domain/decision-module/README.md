Решения объединяются в модуль — контейнер решений, относящихся к одной
системе или подсистеме.

Модуль задает:
- границу, в которой решения образуют единый граф;
- единицу переиспользования: модуль  можно импортировать целиком ссылаться на
  его решения из других модулей (федеративность).
</dec-body>
