Решение состоит из:
- `проблемы` — вопрос "как" (обязательно);
- `тела` — читаемый ответ (проза, диаграммы, обязательно);
- `связей` — на какие решения опирается, какие заменяет;
- `контекста` — к чему относится в системе;
- `статуса` — `действующее`, `заменённое`, `выведенное`;
- `контракта` — чем решение держит другие и чем держится за них.
</dec-body>
