Инструмент программируется на Go.

CUE написан на Go и даёт нативный Go API (`cuelang.org/go/cue`): загрузка,
вычисление и валидация графа в процессе, без вызова CLI-подпроцессом.
Плюс единый бинарь и статическая типизация.

Отвергнуто:
- TypeScript / Python — работа с CUE только через CLI-подпроцесс, не нативно;
- Rust — нет зрелого CUE API.
