Выбрать один единый формат не получилось, из-за различий между телом решения и его структурой.

Что удобно человеку для чтения, неудобно
для валидации, и наоборот.

Форматов несколько, каждый под свою ответственность:
- тело решения — под читаемость;
- структура решения — под строгость и связи.
