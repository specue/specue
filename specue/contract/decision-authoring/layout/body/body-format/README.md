<dec-body>

Тело решения хранится в markdown внутри html тега `<dec-body> <dec-body/>`: проза, списки, диаграммы.

markdown привычен, даёт диаграммы (mermaid) и рендерится где угодно.

Отвергнуто:
- простой текст — нет форматирования и диаграмм;
- HTML — не пишется руками;
- rst/asciidoc — менее распространены.
</dec-body>
