Контракт — часть решения с двумя сторонами: что оно обещает другим и на что само опирается.

- **публичные поля — обещания**: на них опираются другие решения;
- **приватные `_`-поля — опоры**: ссылки на публичные поля чужих контрактов.

В схеме `#Decision` слот контракта открыт (`contract: _`) — закрывает контракт сам автор через `close({...})`. Закрытость нужна, чтобы опора на исчезнувшее поле ломалась (`undefined field`).

```cue
#Decision: {
	problem: string

	contract: _
}
```

```cue
decision: s.#Decision & {
	problem: "Как делать бэкапы заказов"
	contract: close({
		// опора на чужое поле (приватная)

		_storage: orders.decision.contract.storage

		// собственное обещание (публичное)
		tool: "pg_dump"
	})
}
```

`close()` закрывает только верхний уровень — вложенные публичные структуры, на которые опираются, закрывают отдельно.
