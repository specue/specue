Локальная зависимость подменяется на папку с диска через файл
`cue.mod/local-module.cue` рядом с `module.cue`:

```cue
deps: {
	"specue.io/models/decisioning@v0": {
		v:       "v0.0.2"
		replace: "../models/decisioning"
	}
}
```

`replace` — относительный или абсолютный путь к локальному модулю (у него
свой `cue.mod/module.cue`). Зависимость читается с диска, без публикации
в реестр.

Это нативный механизм CUE: его одинаково видят `cue`, LSP в редакторе и
загрузчик инструмента — поэтому правки соседнего модуля видны сразу, без
рассинхрона. Требует `language.version` ≥ v0.17.0; действует, только когда
модуль главный, и в состав модуля не публикуется.
